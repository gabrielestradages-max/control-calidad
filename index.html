CONEXIÓN GOOGLE SHEETS
// Instrucciones de configuración
1
Abre Google Sheets, crea una hoja nueva y nómbrala Registros.
2
En el menú ve a Extensiones → Apps Script. Pega el código que puedes ver con el botón de abajo y haz clic en Implementar → Nueva implementación.
3
Selecciona tipo Aplicación web, ejecución como Yo, acceso para Cualquier usuario. Copia el URL generado.
4
Pega el URL abajo y haz clic en Guardar y conectar.
Deja el campo vacío para desconectar Sheets y trabajar solo en local.
CÓDIGO APPS SCRIPT
Copia todo el código y pégalo en el editor de Apps Script de tu hoja de Google Sheets.
